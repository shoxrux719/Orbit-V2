# ORBIT Campus 2.0 — локальный запуск

Текущая версия: отдельные кабинеты администрации, учителя и ученика,
программа Navigate A1/A2/B1, автоматический журнал домашки, коины с
подтверждением паролем. [Инструкция и границы наполнения](ORBIT-2.0.md).
Материалы конкретного издания Navigate ещё не добавлены; редактор и маршруты готовы.

Ученическая оболочка по шести экранам: Home, Lessons, Practice, Marks, Ranking,
Extra lesson. Светлое оформление ORBIT, постоянная боковая навигация,
мобильное меню и сохранённые кабинеты администрации, учителя и ученика.
Описание обновления: `ORBIT-1.1.md`.

Развёртывание на Vercel: `VERCEL-SETUP.md`. Команда `npm run build` создаёт
серверную функцию и ресурсы Vercel. Для аккаунтов нужна онлайн-база Turso/libSQL;
настройки и первоначальная подготовка описаны в инструкции. Локальная база
и секреты автоматически в облако не копируются.

Закрытый учебный центр с ролями администрации, учителя и ученика.
Самостоятельной регистрации нет. Первый администратор создаётся локальной командой,
дальше только администрация создаёт аккаунты учителей и учеников.

Student: вход по уникальному номеру телефона и паролю. Staff: вход по логину
и паролю. Через Student нельзя открыть кабинет учителя или администрации.
Номер для входа назначает администрация в разделе «Аккаунты»; контактный
телефон в профиле не меняет данные для входа. Для Узбекистана принимаются
9 цифр или международный формат +998. SMS-коды не используются.

Форма Student: отдельный код страны с флагом, номер и пароль. Next доступна
после заполнения корректного номера и пароля; полный вставленный номер
разбирается автоматически. Forgot password? показывает обращение к администрации,
Go back возвращает к выбору профиля.

```powershell
npm run design:build
npm run db:migrate
npm run school:setup
npm start
```

Администрация: http://127.0.0.1:3000/admin.
Учитель: http://127.0.0.1:3000/teacher.
Ученик: http://127.0.0.1:3000/student.
Данные первого администратора записаны в `.local-admin.txt`, который исключён из Git.
Повторный `school:setup` не меняет существующий аккаунт.
Сценарии использования и границы версии описаны в `ORBIT-1.0.md`.

Запускается готовая сборка из `publish-stage-20260920-1500/dist`.

Визуальное оформление редактируется в `design/interface.jsx`,
`design/theme.css`, `design/motion.js` и `design/sphere.svg`.
После правок выполните `npm run design:build` и обновите страницу.
Исходные модули главной сохранены в `design/original`.

```powershell
npm run db:migrate
npm start
```

Сайт доступен по адресу http://127.0.0.1:3000.
Для остановки нажмите Ctrl+C в терминале сервера.

При установленном Node.js ниже версии 22 используется Node.js из среды Codex.
Локальная база хранится в `.wrangler/state`.

Настройки Google в `.dev.vars` сохранены, но Google-вход приостановлен:
в Campus 1.0 создать аккаунт может только администрация.
Старые данные Google и учебные результаты не удаляются.

Новые пошаговые уроки грамматики находятся в `design/grammar.jsx`,
сценарии и практические задания для 18 тем — в `design/grammar-content.js`.
Яркая тема и оформление учебных экранов — в `design/learning.css`.
Сохраняется только результат самостоятельной проверки; тренировочные подсказки
не повышают оценку. Текущий незавершённый урок можно продолжить после обновления
страницы в той же вкладке. Итоги занятий сохраняются на сервере после входа.

Код учебного центра: `design/school.jsx`, `design/school.css`,
`design/school-server.js`, `design/school-schema.sql`.
Миграция `0003_orbit_school.sql` добавляет новые таблицы без изменения старых.
Фото и баннеры сохраняются в локальной D1; браузер уменьшает изображение и удаляет
его метаданные при преобразовании в JPEG. Доступ к изображениям требует входа.

```powershell
npm test
```

50 проверок охватывают учебный контент, сохранённые Google-обработчики и систему
ролей, вход, группы, журнал, домашние задания, приватность и отзыв сессий.
Изолированные проверки не изменяют учебную базу.

Чаты: собственные векторные стикеры ORBIT, эмодзи, реакции, ответы с цитатой,
поиск контактов, статусы прочтения и черновики в текущей вкладке. Исходники:
`design/chat.jsx`, `design/chat.css`, `design/chat-stickers.jsx`, `design/chat-data.js`.
Миграция `0007_chat.sql` добавляет типы сообщений и реакции, сохраняя переписку.

Критические изображения подготовлены в WebP. Фон входа — около 50 КБ на
компьютере и 22 КБ на телефоне. Скрипты и стили получают адреса с отпечатком
версии и долгий кеш на Vercel; кабинету не нужно ждать загрузки рейтинга.
Для повторной подготовки WebP: `node design/optimize-assets.cjs` (Sharp из
зависимостей Wrangler). Готовые изображения включены в репозиторий.
Для отдельной проверки запущенного сервера: `node design/live-academy-check.mjs`;
после проверки удалите только созданные ею данные командой
`node design/live-academy-check.mjs --cleanup`.

Новый код оболочки: `design/campus.jsx`, `design/campus.css`,
`design/campus-icons.jsx`. Сервер: `design/campus-server.js`.
Голосовые комнаты: `design/voice-room.jsx`. Наглядные уроки:
`design/visual-lessons.js`. Миграция 0006 добавляет уникальный номер для входа ученика. Миграции 0004 и 0005 добавляют новые таблицы
и статус отмены слотов. Старые аккаунты, группы и результаты сохраняются.

Для полной локальной проверки новых API сначала создайте тестовые данные
`node design/live-academy-check.mjs`, затем выполните
`node design/live-campus-check.mjs`. Финальная команда очистки выше удаляет
только данные этих проверок, включая временные сообщения, награды и слоты.
